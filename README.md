# BDArmory GPS Preloader (BDGPSPreloader)

Ce mod pour Kerbal Space Program (KSP) permet de préparer et de stocker des coordonnées GPS à l'avance pour ensuite les envoyer rapidement dans le système de ciblage de **BDArmory**.

## Installation

1. Compilez le projet C# ou téléchargez la DLL compilée `BDGPSPreloader.dll`.
2. Placez-la dans `Kerbal Space Program/GameData/BDGPSPreloader/Plugins/BDGPSPreloader.dll`.
3. Lancez le jeu.

## Utilisation

1. En vol, cliquez sur l'icône de l'application dans la barre d'outils.
2. Saisissez le **Nom**, la **Latitude**, la **Longitude** et **l'Altitude** de la cible désirée.
3. Cliquez sur **Enregistrer la coordonnée**.
4. Pour charger une coordonnée dans le système de BDArmory, cliquez sur **Injecter** à côté de la coordonnée souhaitée dans la liste.
